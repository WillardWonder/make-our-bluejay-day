# Make Our Bluejay Day

Sponsor-a-day fundraiser page for Merrill High School girls wrestling, 2026–27.

This repo is the front end in **preview mode** (sample data; nothing is saved and no money moves). Each girl's preview page is the site link plus `#her-link`, e.g. `#addison-clark`.

The live version runs on Firebase Hosting with the backend deployed, where each girl's link is a clean path like `/addison-clark`.
